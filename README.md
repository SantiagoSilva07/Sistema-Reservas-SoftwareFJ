Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto desarrollado para la Fase 4 - Prácticas Simuladas del curso Programación (213023) de la UNAD.

DESCRIPCIÓN

Software FJ es una empresa dedicada a la prestación de servicios tecnológicos, entre ellos:

Reserva de salas.
Alquiler de equipos.
Asesorías especializadas.

El proyecto consiste en desarrollar un sistema orientado a objetos que permita gestionar clientes, servicios y reservas, implementando manejo avanzado de excepciones y registro de eventos mediante archivos de log.

OBJETIVOS

Aplicar los principios de Programación Orientada a Objetos.
Implementar abstracción, herencia, encapsulación y polimorfismo.
Gestionar clientes, servicios y reservas mediante objetos y listas.
Implementar excepciones personalizadas y manejo de errores.
Registrar eventos y errores en archivos log.
Realizar simulaciones válidas e inválidas que demuestren la estabilidad del sistema.
