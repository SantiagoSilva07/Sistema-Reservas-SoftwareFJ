SISTEMA INTEGRAL DE GESTIÓN DE CLIENTES, SERVICIOS Y RESERVAS

Proyecto desarrollado para la Fase 4 - Prácticas Simuladas del curso Programación (213023) de la Universidad Nacional Abierta y a Distancia (UNAD).

DESCRIPCIÓN

Software FJ es una empresa dedicada a la prestación de servicios tecnológicos tales como:

Reserva de salas.
Alquiler de equipos.
Asesorías especializadas.

El proyecto consiste en desarrollar un sistema orientado a objetos capaz de gestionar clientes, servicios y reservas, implementando manejo avanzado de excepciones y registro de eventos mediante archivos de log, sin utilizar bases de datos.

OBJETIVOS

Aplicar los principios de Programación Orientada a Objetos.
Implementar abstracción, herencia, encapsulación y polimorfismo.
Gestionar clientes, servicios y reservas mediante objetos y listas.
Implementar excepciones personalizadas y manejo avanzado de errores.
Registrar eventos y errores mediante archivos log.
Realizar simulaciones válidas e inválidas garantizando la continuidad del sistema.
